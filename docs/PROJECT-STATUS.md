## 1. 우리가 푸는 문제

한국 부동산 시장에는 **중개사 가로채기**라는 구조적 문제가 있다.

매도자가 A 중개사에게 매물을 맡겨 일을 시켰지만, 거래는 마지막 순간에 끼어든 B 중개사에게 가버린다. A는 시간과 돈을 쏟았는데 보수는 0원. 결과: 중개사가 매도자를 피하거나, 이중 보수를 요구하거나, 시장 자체를 떠난다.

기존 MLS는 이걸 못 풀었다 — *"먼저 등록한 사람이 임자"* 라는 단일 시간 룰만으로는 부족하기 때문이다 (선착순 변수 하나면 카카오 부동산처럼 빠르게 독점이 형성된다).

---

## 2. 우리가 만든 것

**MyHome은 "누가 먼저 일을 시작했는지를 코드로 증명하는 첫 부동산 플랫폼"이다.**

세 가지가 핵심이다:

### 2-1. 시간이 박힌 "우선권" (M1)
중개사가 매도자나 매수자를 만나면 시스템이 *자동으로* 우선권을 발급한다. 누가 먼저 움직였는지 변조 불가능한 기록으로 남는다.

### 2-2. 일하지 않으면 사라짐 (Use-it-or-Lose-it)
우선권을 받았다고 끝이 아니다. 14~30일 안에 80% 이상 활동(연락·방문·제안)하지 않으면 자동 만료. *책상에 앉아만 있는 중개사는 우선권을 잃는다.*

### 2-3. 80세 노인도 이해되는 단순함
"점수", "%", "가중치" 같은 말은 사용자 화면에 한 글자도 안 나온다. 매도자에게는 "○○님이 지금 맡고 있어요" 정도로만 보인다. 이해 못하면 큰 거래를 하지 않는다는 본질을 끝까지 지켰다.

---

## 3. 어떻게 작동하는가 (실제 흐름)

```
매도자가 매물 등록
    ↓
주변 중개사들에게 자동 배포 (1km → 동 → 인접동 → 광역, 단계적)
    ↓
중개사가 매수자 데려와 방문 신청
    ↓
첫 방문 승인 시점 = "선등록 우선권" 자동 발급
    ↓
14~30일 동안 그 중개사가 80% 이상 활동
    ↓ (활동 못하면 자동 만료, 우선권은 다음 사람에게)
    ↓
거래 성사 → 매도자가 [거래 성사로 끝내기] 한 번 누름
    ↓
끝.
```

**누구의 손에도 보수 분배 코드가 들어가지 않는다.** 보수 다툼은 §32·§33 공인중개사법 영역. 우리는 *시간 사실*만 코드로 박는다. 누가 먼저였는지 다툴 일이 없게 만드는 게 우리 일.

## 4. 경쟁사와 무엇이 다른가

| 비교 | 기존 플랫폼 | MyHome v1.4.1 |
|---|---|---|
| 우선권 결정 | 단순 선착순 또는 약관 안내 | **여러 변수 가중 + 코드 강제** (지역·면허·활동률 등) |
| 활동 안 한 중개사 | 그냥 보유 | **자동 만료** (80% 룰) |
| 분쟁 처리 | 약관에 "협의로" | **별도 이의 제기 채널 + 관리자 검토 + 결정 재현** |
| 점유율 독점 | 추적 안 함 | **30% 도달 시 외부 감사 자동 발동** |
| 사용자 화면 | 점수·등급 노출 | **점수 0건 노출** (80세 노인 테스트) |
| 매도자 자율성 | 단독 지정 막힘 | **단독 모드 직접 선택 가능** |

## 7. 알아야 할 위험과 대응

### 7-1. 법령 리스크 — §32·§33 공인중개사법
**현재 대응**: 우리는 보수 분배·차감 코드를 *한 줄도* 갖지 않는다. 시간 사실만 박는다. 모든 PR에 법무 자가 점검 표 첨부 강제.

### 7-2. 카카오 회피
대형 플랫폼이 빠르게 독점하면 시장이 망가진다. **우리는 점유율 30%가 임계선** — 도달 시 외부 감사 자동 발동되도록 코드에 박아 둠.

### 7-3. 80세 노인 테스트 위반
누군가 화면에 "82점", "1순위" 같은 단어를 넣으면 즉시 PR 거절. **체크리스트 21개 + 80세 가상 인터뷰 6 질문 통과** 없이 머지 불가.

### 7-4. 사용자 신뢰
알고리즘이 깜깜이면 누구도 안 쓴다. **`/rulebook` 페이지가 모든 산정 변수를 공개** — 매도자도 중개사도 볼 수 있다. 이의 제기는 누구나 할 수 있고 결정은 재현 가능.
