# 구매자 UX 분석

## 1. 현재 워크플로우 (실제 구현 기준)

```
[비로그인 경로]
앱 진입 → AuthLandingPage (로그인 강제)
  → "일단 둘러보기" 없음 ← 문제

[로그인 후 경로]
MainPage 탭 0 (등록) ← 구매자에게 완전히 부적절한 랜딩
  → 탭 3 (탐색)으로 이동
  → PublicListingsPage
  → 매물 카드 클릭
  → PublicPropertyDetailPage
  → "이 매물 문의하기" 버튼
  → 다이얼로그 (메모 입력)
  → "문의 보내기"
  → 완료 (더 이상 추적 방법 없음)
```

---

## 2. 잡스 3단계 압축 검토

**이상적인 3단계:**
```
매물 탐색 → 상세 확인 → 문의하기
```

**현재 현실 (비로그인 구매자):**
```
앱 설치(1) → 로그인 강제(2) → 가입(3) → 랜딩이 등록화면(4)
→ 탭 3 찾기(5) → 탐색(6) → 상세보기(7) → 문의(8) → 끝
(이후 상태 추적 방법 없음)
```

**판정: ❌ 실패 (8단계 + 사후 추적 불가)**

경쟁사 비교:
- 네이버부동산: 앱 열기 → 지역 선택 → 매물 보기 (3단계, 로그인 불필요)
- 직방: 앱 열기 → 지역/유형 선택 → 매물 목록 (3단계, 로그인 불필요)

---

## 3. 마찰 포인트

### 🔴 Critical

**[B-001] 비로그인 매물 탐색 불가 (앱 진입 시)**
- AuthLandingPage가 강제 로그인 장벽
- 구매자는 "어떤 매물이 있는지" 먼저 보고 싶어함
- 로그인 없이 매물 탐색 → 마음에 들면 로그인 → 문의 흐름이 자연스러움
- 현재: 매물도 보기 전에 로그인 요구 → 이탈률 높음
- 개선: AuthLandingPage에 "먼저 매물 둘러보기" 버튼 → PublicListingsPage

**[B-002] 로그인 후 구매자 랜딩이 "등록" 탭**
- 구매자가 로그인하면 매물 등록 화면이 뜸 (완전히 다른 니즈)
- 사용자 역할(매도자/구매자/중개사)에 따른 랜딩 분기 없음
- 개선: 구매자 역할 추가 또는 탭 3(탐색)을 비로그인 포함 기본 탭으로

**[B-003] 문의 후 상태 추적 화면 없음**
- "문의 접수됨" 메시지 이후 → 내 문의 목록 화면 없음
- "어느 중개사가 배정됐나?", "연락처가 뭔가?", "몇 개 문의했나?" 확인 불가
- buyer-strategy-analysis.md 6절에 명세된 "내 문의" 화면이 미구현
- 개선: MainPage에 "내 문의" 탭 또는 MyInquiriesPage 신규 생성

**[B-004] 문의 후 중개사 연락처를 구매자가 볼 방법 없음**
- BuyerInquiry에 assignedBrokerId가 저장되지만 구매자가 볼 UI 없음
- 중개사가 연락할 때까지 구매자는 무한 대기 상태
- 개선: 배정 완료 시 FCM + "내 문의" 화면에 중개사 정보 표시

### 🟡 Important

**[B-005] 찜/관심 기능 없음**
- 여러 매물을 탐색하면서 마음에 드는 것 저장 불가
- 다음 접속 시 다시 찾아야 함
- buyer-strategy-analysis.md 3.1 B단계에 "관심 등록" 언급됨
- 개선: 하트 버튼 → favorites 컬렉션 저장 → 별도 탭 or 필터

**[B-006] 매물 카드에 구매 관심자 수 미표시**
- buyer-strategy-analysis.md 6.2절에 "관심 8명" 표시 명세됐으나 미구현
- 수요 신호가 보이면 구매 결정 촉진 효과 (FOMO)
- 개선: PublicListingsPage 카드에 "관심 N명" 뱃지

**[B-007] 지역 필터 후 결과 없을 때 안내 부족**
- 특정 지역 선택 시 매물 없으면 빈 화면만 표시
- 개선: "이 지역 매물 알림 받기" CTA 또는 인접 지역 매물 추천

### 🟢 Minor

**[B-008] 구매자 온보딩 없음**
- 플랫폼의 역경매 구조(허위매물 없음, 중개사 경쟁)를 구매자가 모름
- 첫 문의 전 간단한 안내 화면 없음

**[B-009] 매물 공유 기능 없음**
- 가족/지인과 매물 링크 공유 불가 (배우자와 함께 결정하는 한국 부동산 특성)

## 4. 구매자의 핵심 욕구 충족 여부

| 욕구 | 현재 충족도 | 비고 |
|------|------------|------|
| 허위매물 없는 탐색 | ✅ 충족 | 매도자 직접등록 구조 |
| 로그인 없이 매물 탐색 | 🔴 미충족 | 강제 로그인 장벽 |
| 빠른 문의 | 🟡 보통 | 문의 자체는 쉬우나 찾아가는 경로가 복잡 |
| 문의 상태 추적 | 🔴 미충족 | 화면 자체 없음 |
| 관심 매물 저장 | 🔴 미충족 | 찜 기능 없음 |
| 중개사 연락 수신 | 🔴 미충족 | UI 없음 (오프라인 전화만) |
