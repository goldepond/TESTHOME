# 매도자 UX 분석

## 1. 현재 워크플로우 (실제 구현 기준)

```
로그인
  ↓
MainPage 탭 0 (등록) ← 기본 탭
  ↓
MLSQuickRegistrationPage
  ├─ 주소 검색
  ├─ 가격 정보 (희망가, 협상가능여부, 최소희망가)
  ├─ 이사 시기 (즉시/협의/특정일)
  ├─ 수리 상태 (올수리/부분/필요 + 수리내역)
  ├─ 옵션 선택 (14개 항목)
  ├─ 셀링 포인트 (14개 항목)
  └─ 사진 등록
  ↓
등록 완료 → MLSSellerDashboardPage (탭 1)
  ↓
매물 클릭 → MLSPropertyDetailPage
  ├─ 중개사 목록 확인
  ├─ 중개사 승인/거절
  └─ 방문 요청 관리
```

---

## 2. 잡스 3단계 압축 검토

**이상적인 3단계:**
```
주소 입력 → 가격 설정 → 등록 완료
```

**현재 현실:**
```
주소검색(1) → 가격입력(2) → 이사시기(3) → 수리상태(4)
→ 옵션선택(5) → 셀링포인트(6) → 사진등록(7) → 등록(8)
```

**판정: ❌ 실패 (8단계)**

단계가 많은 건 부동산 매물의 정보량 특성상 불가피하지만,
**필수/선택 구분 없이 한 번에 다 요구하는 구조**가 문제.

**개선 방향:**
```
[필수 - 즉시등록]
주소 → 가격 → 등록 (3단계)
            ↓ 나중에 보완
[선택 - 나중에 입력]
수리상태 / 옵션 / 셀링포인트 / 사진
(등록 후 대시보드에서 추가 입력 유도)
```

## 3. 마찰 포인트

### 🔴 Critical

**[S-001] 기본 탭이 항상 "등록"**
- 매물을 이미 등록한 사용자가 로그인할 때마다 등록 화면이 뜸
- 1개 매물 이상 있는 사용자는 탭 1(내 매물)이 더 자연스러운 랜딩
- 개선: 등록 매물 존재 여부에 따라 기본 탭 동적 결정

**[S-002] 구매 관심자 수가 매도자에게 보이지 않음**
- BuyerInquiry가 Firestore에 쌓이는데 매도자 대시보드에 카운트 없음
- "내 매물에 8명이 관심" 같은 정보가 매도자 동기 부여에 핵심
- buyer-strategy-analysis.md 5.2절에 명시된 기능인데 미구현
- 개선: MLSSellerDashboardPage 매물 카드에 관심자 수 뱃지 추가

**[S-003] 중개사 승인 후 다음 단계 안내 없음**
- 중개사 승인(연락처 교환) 후 "이제 어떻게 됩니까?" 안내 없음
- 사용자가 다음 행동을 모름
- 개선: 승인 완료 다이얼로그에 "중개사가 방문 일정을 조율할 예정입니다" 안내

### 🟡 Important

**[S-004] 방문 요청 관리 UI 미흡**
- VisitRequest 모델은 있으나 매도자가 방문 일정을 승인/거절하는 UI 불명확
- 중개사-매도자 방문 일정 조율 흐름이 끊김

**[S-005] 매물 수정 진입점 불명확**
- MLSPropertyDetailPage에서 수정 버튼이 있는지 명확하지 않음
- 가격 조정, 이사 시기 변경 등 자주 발생하는 수정이 쉬워야 함

**[S-006] 매물 상태 변경 UI 부재**
- 협상 시작(underOffer), 가계약(depositTaken) 등 매물 상태를 매도자가 직접 변경하는 UI 없음
- 현재는 관리자 또는 시스템만 가능 추정

### 🟢 Minor

**[S-007] 등록 완료 후 피드백 약함**
- "등록되었습니다" 메시지 후 탭 1로 이동하는데, 다음 행동 안내 없음
- 개선: "중개사들에게 알림이 발송되었습니다. 중개사 제안을 기다려 주세요."

**[S-008] 시세 탭(탭 2)과 내 매물의 연결 없음**
- 현재 매물의 시세 대비 내 가격 위치를 즉시 확인할 수 없음
- 매물 상세에서 "시세 비교" 바로가기 있으면 가격 설정에 도움

## 4. 매도자의 핵심 욕구 충족 여부

| 욕구 | 현재 충족도 | 비고 |
|------|------------|------|
| 빠른 등록 | 🟡 보통 | 8단계 → 3단계 개선 필요 |
| 내 매물 현황 확인 | 🟡 보통 | 중개사 현황은 보이나 구매자 관심 안 보임 |
| 중개사 선택권 | ✅ 충족 | 승인/거절 기능 있음 |
| 적정 가격 판단 | 🟡 보통 | 시세 탭은 있으나 내 매물과 연결 없음 |
| 거래 진행 상황 | 🔴 미흡 | 방문→협상→계약 흐름 UI 없음 |
