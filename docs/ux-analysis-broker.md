# 공인중개사 UX 분석

## 1. 현재 워크플로우 (실제 구현 기준)

```
중개사 로그인
  ↓
MLSBrokerDashboardPage
  ├─ 탭 0: 매물 탐색 (기본)
  │   ├─ 지역 필터
  │   ├─ 가격/유형/상태 필터
  │   ├─ 매물 카드 목록
  │   └─ 매물 클릭 → 상세보기 → "중개 제안하기"
  │       └─ 다이얼로그 (이름, 전화, 회사명, 한마디)
  │
  ├─ 탭 1: 내 참여 매물
  │   └─ 제안 완료한 매물 목록 (상태별)
  │
  ├─ 탭 2: 경쟁 현황
  │   └─ 같은 매물에 참여한 다른 중개사 목록
  │
  ├─ 탭 3: 완료된 거래
  │   └─ 거래 완료 매물
  │
  └─ 탭 4: 설정 (BrokerSettingsPage)
      └─ 기본 정보, 사업자 정보, 소개, 인증 상태
```

---

## 2. 잡스 3단계 압축 검토

**핵심 워크플로우 A: 새 매물에 중개 제안**
```
이상적: 매물 발견 → 관심 → 제안
현재:   탐색(1) → 필터(2) → 목록(3) → 클릭(4) → 상세(5) → 버튼(6) → 다이얼로그(7) → 제출(8)
```
**판정: 🟡 보통 (8단계이나 각 단계가 가볍고 자연스러움)**

**핵심 워크플로우 B: 구매자 리드 확인 (신규)**
```
이상적: 알림 수신 → 구매자 정보 확인 → 연락
현재:   알림은 오는데 → 확인할 화면 없음 → 대시보드 어딘가 있겠지 → 못 찾음
```
**판정: ❌ 실패 (화면 자체 없음)**

**핵심 워크플로우 C: 신규 중개사 가입 후 첫 사용**
```
이상적: 가입 → 인증 → 제안
현재:   가입(1) → "관리자 인증 대기 중"(2) → 무한 대기... → 인증 완료 알림 없음
```
**판정: ❌ 실패 (인증 완료 알림 없음, 대기 중 할 수 있는 게 없음)**

## 3. 마찰 포인트

### 🔴 Critical

**[BR-001] 구매자 리드 확인 화면 없음 (또는 숨겨짐)**
- buyer-strategy-analysis.md에 따르면 BuyerInquiry가 오면 해당 지역 중개사에게 알림
- 중개사 대시보드에 "구매 리드" 탭이 있어야 하지만 현재 탭 구성에서 불명확
- 구매자 리드가 중개사의 핵심 가치인데 눈에 안 띄면 플랫폼 가치 반감
- 개선: 탭 1을 "내 리드" (구매자 리드 + 내 제안 매물)로 재편

**[BR-002] 인증 대기 상태에서 할 수 있는 게 없음**
- 신규 중개사가 가입 → 인증 대기 → 대시보드는 보이지만 제안 불가
- "인증 완료" 알림이 FCM으로 오는지 불명확
- 대기 중 기간(보통 1~2일) 동안 매물 탐색만 가능
- 개선: 인증 완료 시 즉시 FCM 푸시 + 이메일 알림

**[BR-003] 제안 후 매도자 결정까지 피드백 없음**
- 중개 제안 후 매도자가 승인/거절할 때까지 진행 상황 불투명
- "내 참여 매물" 탭에서 상태 확인이 가능하지만 UI 명확도 미확인
- 개선: 매도자 결정 시 즉시 FCM 알림 (현재 FCM 타입 목록에 미포함)

### 🟡 Important

**[BR-004] 탭 2 "경쟁 현황"의 실용성 의문**
- 같은 매물에 다른 중개사가 몇 명인지 아는 게 실제로 유용한가?
- 중개사가 이 정보로 무엇을 할 수 있는가? (포기? 더 적극적 제안?)
- 경쟁 현황 대신 "내 성과 통계" (제안 수락률, 거래 완료 수)가 더 유용할 수 있음

**[BR-005] 제안 시 중개사 정보 매번 입력**
- 이름, 전화, 회사명을 매물마다 다시 입력 (자동완성 불명확)
- BrokerSettings에서 저장된 정보를 자동으로 불러와야 함
- 개선: 제안 다이얼로그에 저장된 정보 자동 입력 + 수정 가능

**[BR-006] 지역 필터가 광역시/도 단위로만 가능**
- 서울 → 강남구 → 역삼동 수준의 세부 필터 없음
- 중개사는 특정 동네만 담당하는 경우가 많음
- 개선: 기존 RegionSelectionMap 위젯을 활용한 세부 지역 설정

**[BR-007] 구매자 리드 수신 시 우선 매물 탐색 없음**
- "OO동 매물에 구매 관심자가 있습니다" 알림 → 해당 매물로 바로 이동 불가
- 알림 클릭 → NotificationPage만 이동 → 해당 매물 찾아야 함

### 🟢 Minor

**[BR-008] 탭 3 "완료된 거래"와 탭 1 "내 참여 매물" 중복 가능성**
- 완료된 거래가 탭 1에도 포함되는지 분리 기준 불명확
- 개선: 탭 1은 진행 중만, 탭 3은 완료만 명확히 분리

**[BR-009] 중개사 성과 데이터 본인 확인 불가**
- AdminBrokerStatsPage에는 통계가 있으나 중개사 본인은 볼 수 없음
- "내 성과 요약" (제안 N건, 승인 N건, 거래완료 N건)을 설정 탭에 추가

## 4. 중개사의 핵심 욕구 충족 여부

| 욕구 | 현재 충족도 | 비고 |
|------|------------|------|
| 무료 매물 확보 | ✅ 충족 | 핵심 가치 충족 |
| 빠른 매물 발견 및 제안 | 🟡 보통 | 세부 지역 필터 없음 |
| 구매자 리드 수신 | 🔴 미충족 | 화면 불명확 |
| 인증 및 온보딩 | 🟡 보통 | 완료 알림 없음 |
| 본인 성과 확인 | 🔴 미충족 | 관리자만 볼 수 있음 |
| 매도자 결정 알림 | 🟡 보통 | FCM은 있으나 타입 불명확 |
