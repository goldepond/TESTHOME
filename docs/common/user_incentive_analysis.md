# MyHome 3자 사용자 유인 구조 분석

> 작성일: 2026-04-18
> 대상: MyHome MLS 플랫폼 (판매자 / 공인중개사 / 구매자)
> 관점: 비즈니스 · 사용자 경험 · 논리적 성립 가능성

---

## 요약 (Executive Summary)

MyHome은 **"매도인 1회 등록 → 지역 내 중개사 전체에 자동 배포"** 라는 MLS 모델을 기반으로, 행동 데이터 기반 중개사 신뢰도를 결합한 부동산 플랫폼이다. 설계 자체는 한국 부동산 시장의 고질적 문제(정보 비대칭·중개사 독점 정보)를 해결하려는 논리적 구조를 갖추고 있다.

그러나 3자(판매자·중개사·구매자)의 유인을 각각 분해해보면, **유인 구조의 완성도는 불균형하다.**

| 주체 | 유인 명확성 | 구조 완성도 | 초기 성립 가능성 | 종합 |
|------|:---:|:---:|:---:|:---:|
| 판매자 | ★★★★☆ | ★★★★☆ | ★★★☆☆ | **7/10** |
| 중개사 | ★★★☆☆ | ★★★☆☆ | ★★☆☆☆ | **5/10** |
| 구매자 | ★★☆☆☆ | ★★★☆☆ | ★☆☆☆☆ | **4/10** |

**한 줄 진단**: *구조는 설계되었으나, 세 사용자 모두에게 유인이 실제로 작동하려면 Cold Start 극복 장치와 최소 수익 모델이 부재하다.*

## 1. 플랫폼의 가치 제안

### 해결하려는 문제
1. **판매자-중개사 정보 비대칭**: 판매자는 중개사의 실제 실력을 알 수 없고, 특정 중개사에게 맡기면 노출이 제한된다.
2. **중개사의 폐쇄적 매물 보유**: 특정 중개사가 매물을 독점하면 구매자 선택권이 좁아진다.
3. **중개 품질의 불투명성**: 별점·리뷰는 조작되기 쉽고, 실제 거래 능력과 무관하다.

### 핵심 메커니즘
- **MLS(Multiple Listing Service) 자동 배포**: 매물 1회 등록으로 지역 전체 중개사가 동시 접근
- **행동 데이터 기반 신뢰도**: 별점 대신 방문성사율·노쇼율·제안가 정직도·응답속도로 평가
- **연락처 비공개 원칙**: 판매자 승인 전까지 중개사와 연락처 공유 차단

### 기존 시장 대비 포지션
| 구분 | 네이버부동산/직방/다방 | MyHome |
|------|--------------------|--------|
| 매물 주도권 | 중개사가 등록 | 판매자가 등록 |
| 중개사 노출 방식 | 광고비 순 | 행동 데이터 순 |
| 구매자 매칭 | 사용자가 중개사 선택 | 자동 매칭 |
| 수익 모델 | 광고·프리미엄 | 현재 없음 |

MyHome은 기존 앱과 **"매물 등록 주체"** 자체가 다르다. 이것이 유일하지만 결정적인 차별점이다.

## 2. 판매자 관점 분석

### 2.1 비즈니스 관점

판매자가 원하는 궁극적 가치는 두 가지다: **빠른 거래 성사**와 **최대한 좋은 가격**. 이를 위해 판매자는 전통적으로 "신뢰할 수 있는 중개사 1-2명"에게 의뢰해왔다. 이 방식의 한계는 **노출도 제약**과 **중개사 의존 리스크**다.

MyHome이 제안하는 구조는 정확히 이 지점을 공격한다: 판매자는 매물을 한 번 등록하는 것만으로 지역 내 다수 중개사와 접촉하고, 중개사들 간 경쟁이 발생한다. 여기에 중개사 행동 데이터가 공개되므로, 판매자는 단순히 "많은 중개사"가 아니라 "검증된 중개사들 중 경쟁"을 얻는다.

### 2.2 사용자 경험 관점

- **등록 편의성**: 빠른 등록 경로로 5분 내 완료 가능, 기본 등록으로 상세 정보 관리
- **프라이버시 보호**: 판매자가 승인하기 전까지 연락처는 공개되지 않음
- **방문 스케줄 통제권**: 가용 시간대를 판매자가 설정, 중개사 요청은 그 범위 내에서만 가능
- **상태 가시성**: draft → pending → active → inquiry → underOffer → depositTaken → sold 의 명확한 단계 관리

### 2.3 논리적 관점: 유인이 충분한가?

**성립하는 이유**
- 기존에 1-2명 중개사에게 맡기던 것 대비 구조적으로 노출이 극대화된다. 이는 수학적으로 반박하기 어려운 이득이다.
- 플랫폼 이용료 0원이므로, **"손해볼 것이 없다"** 는 진입 심리가 형성된다.
- 신뢰도 지표가 공개되므로, 중개사를 아예 모르는 초심자도 의사결정할 수 있다.

**결함과 한계**
- **All-or-Nothing 배포**: 판매자가 배포 대상 중개사를 선별·차단할 권한이 없다. 특정 중개사와의 악연이 있거나 지역 내 친인척 관계를 피하고 싶어도 현재 구조로는 불가능하다. 부동산 거래처럼 프라이버시 민감도가 높은 영역에서 이는 치명적 장애다.
- **신뢰도 지표의 콜드스타트**: 데이터가 쌓이지 않은 초기에는 모든 중개사가 "판단 불가"로 표시되어 지표가 무력화된다. 플랫폼 초반 판매자는 "어차피 지표 없는데 왜 여기서?" 라는 의문을 갖게 된다.
- **매물 다수 노출의 역효과**: 수십 명 중개사에게 동시 노출되면, 거꾸로 "이미 다 퍼진 매물"로 인식되어 가격 협상력이 떨어질 수 있다.

### 2.4 구조 완성도

| 영역 | 상태 |
|------|------|
| 매물 등록 / 수정 | ✅ 완성 |
| 상태 전이 관리 | ✅ 완성 |
| 방문 요청 승인·거절 | ✅ 완성 |
| 중개사 신뢰도 조회 | ✅ 완성 |
| 거래 완료 기록 | ✅ 완성 |
| **중개사 차단·선별** | ❌ 미구현 |
| **특정 중개사 지정 배포** | ❌ 미구현 |
| **재등록·알림 관리** | ⚠️ 부분 |

**소결**: 판매자는 3자 중 가장 유인 구조가 강하고 기능도 성숙해 있다. 다만 "배포 통제권 부재"는 반드시 보완되어야 한다.

## 3. 공인중개사 관점 분석

### 3.1 비즈니스 관점

중개사의 KPI는 단순하다: **유효 리드 수 × 성사율 × 건당 수수료**. 중개사가 새 플랫폼에 시간을 투자할 때의 의사결정 기준도 결국 "여기서 리드가 나오는가"다.

MyHome의 제안은 "지역에서 등록되는 매물을 무료로 모두 볼 수 있다"는 것이다. 이는 리드 취득 비용이 0이라는 점에서 강력한 미끼지만, 중요한 문제가 있다: **매물 자체가 리드가 아니다.** 매물은 판매 상품이고, 리드는 그 매물을 살 구매자다. MyHome 구조에서 중개사가 얻는 "리드"는 실제로는 판매자와의 접촉 기회이며, 구매자 리드는 BuyerInquiry 배정을 통해서만 제한적으로 받는다.

### 3.2 사용자 경험 관점

- 5개 탭 대시보드(매물/관심/내 제안/성과/구매 리드)로 구조화
- 지역 필터링으로 관심 외 매물 제외 가능
- 방문 요청 제출 프로세스 간결
- 신뢰도 지표를 중개사 본인도 확인 가능

### 3.3 논리적 관점: 유인이 충분한가?

**성립하는 이유**
- **신규·소형 중개사**에게 무료 리드는 매우 강력한 유인이다. 기존 플랫폼은 광고비 경쟁이 치열해 진입장벽이 높다.
- 행동 데이터로 차별화할 수 있는 구조는 실력 있는 신규 중개사에게 기회를 제공한다.

**결함과 한계**
- **대형 중개사는 전환할 이유가 없다**: 이미 자체 고객 풀과 프랜차이즈 지원을 가진 중개사가 굳이 경쟁 구조에 들어올 이유가 약하다. 오히려 자신의 독점 매물을 공유해야 한다면 반발할 수 있다.
- **Chicken-and-Egg**: 중개사는 판매자가 많을 때 오고, 판매자는 중개사가 많을 때 온다. MyHome은 현재 이 고리를 깰 선제적 인센티브(초기 리드 할당 보장, 지역 독점권, 모집 포상 등)가 없다.
- **신뢰도 지표의 역설**: 초기에 진입한 중개사가 노쇼 1건이라도 기록되면 작은 표본에 크게 오염되어 통계가 왜곡된다. 이는 초기 중개사에게 "참여할수록 손해"인 구조를 만들 위험이 있다.
- **수익 회수 경로 불투명**: 중개사 입장에서 중개 수수료는 전적으로 오프라인 협상이므로, 플랫폼이 중개사의 거래 성사를 얼마나 효과적으로 도와주는지 증명하기 어렵다.

### 3.4 구조 완성도

| 영역 | 상태 |
|------|------|
| 매물 브라우징 / 필터 | ✅ 완성 |
| 방문 요청 제출 | ✅ 완성 |
| 성과 추적 (완료 매물) | ✅ 완성 |
| 신뢰도 지표 축적 | ✅ 완성 |
| **BrokerOffer(경쟁 제안) UI** | ⚠️ 모델만 존재, 화면 미완성 |
| **중개사 모집 프로그램** | ❌ 미구현 |
| **프리미엄·광고 수익 모델** | ❌ 미구현 |
| **신규 중개사 보호 기간·배지** | ❌ 미구현 |

**소결**: 중개사 측 유인은 "무료"라는 단일 요소에 과도하게 의존한다. 무료만으로는 대형 중개사 유치가 불가능하고, 신뢰도 시스템의 콜드스타트 문제도 해결되지 않았다.

## 4. 구매자 관점 분석

### 4.1 비즈니스 관점

구매자가 부동산 앱에 요구하는 것은 본질적으로 세 가지다: **많은 매물**, **강력한 검색·필터**, **신뢰할 수 있는 시세 정보**. 이 중 하나라도 크게 부족하면 다른 앱으로 떠난다. 구매자는 판매자·중개사와 달리 "등록"이라는 종속적 행위를 하지 않으므로 전환 비용이 거의 0이다.

MyHome이 구매자에게 약속하는 것은 "자동 중개사 매칭"과 "공개 실거래가 조회"다. 전자는 문의 시 부담을 낮추는 UX 개선이고, 후자는 비로그인 SEO 유입 유도책이다.

### 4.2 사용자 경험 관점

- 로그인 없이 매물 목록·상세·시세 조회 가능
- 찜하기·문의하기 지원
- 문의 시 담당 중개사 자동 배정(Load-balanced)
- 문의 상태 6단계 추적

### 4.3 논리적 관점: 유인이 충분한가?

**치명적 결함 1 — 매물 공급량 열세**
구매자에게 가장 중요한 요소는 "볼 매물이 얼마나 있는가"다. 직방·다방·네이버부동산은 수십만 건의 매물을 보유하고 있으며, 구매자는 이미 그곳에서 충분히 탐색할 수 있다. MyHome의 매물 공급이 이들 대비 1/100 수준이라면, 구매자가 MyHome을 **추가로 사용할 이유**가 있어야 한다. 현재 그 "추가 이유"가 명확하지 않다.

**결함 2 — 검색·필터 경쟁력 부재**
가격 범위, 전용 면적, 방 개수, 건축 연도, 지도 기반 탐색 등 경쟁 앱이 기본 제공하는 필터가 미흡하다. 매물 수가 적다는 약점을 UX로도 보완하지 못하는 상태다.

**결함 3 — 자동 매칭의 양면성**
"중개사를 직접 고르지 않아도 된다"는 것은 초보 구매자에게는 편리하지만, 숙련된 구매자·자산가·지역 전문성을 중시하는 구매자에게는 오히려 불편하다. 자동 매칭은 호불호가 강한 기능이지 보편적 유인이 아니다.

**결함 4 — SEO 유입과 전환의 단절**
공개 매물 페이지와 실거래가 조회는 SEO 유입을 유도하지만, 유입된 사용자가 "이 앱에 로그인하여 문의하겠다"는 결정까지 이어지게 할 전환 장치가 부족하다. 시세 조회 결과에서 관련 매물로 연결되는 동선, 가격 변동 알림, 관심 지역 신규 매물 푸시 등이 없다.

**유일하게 작동 가능한 유인**
- 일반 앱에서 꺼려하는 **"전화번호 공개 없이 문의"** 는 특정 심리적 문턱(개인정보 노출 부담)이 있는 구매자에게 매력적이다.

### 4.4 구조 완성도

| 영역 | 상태 |
|------|------|
| 공개 매물·시세 열람 | ✅ 완성 |
| 찜하기 | ✅ 완성 |
| 문의 + 자동 중개사 배정 | ✅ 완성 |
| 문의 상태 추적 | ✅ 완성 |
| **고급 검색·필터** | ❌ 미구현 (치명적) |
| **지도 기반 탐색** | ❌ 미구현 (치명적) |
| **가격·신규 매물 알림** | ❌ 미구현 |
| **매물 비교 기능** | ❌ 미구현 |
| **시세 ↔ 매물 연계** | ❌ 미구현 |

**소결**: 구매자 측은 **3자 중 유인이 가장 약한 고리**다. 현재 상태로는 구매자가 MyHome을 주력 앱으로 쓸 이유가 희박하다.

## 5. 3자 네트워크 효과 분석

### 5.1 Cold Start 구조

플랫폼의 가치는 사용자 수가 임계점을 넘었을 때 폭발한다. MyHome의 의존 고리는 다음과 같다:

```
판매자 매물 등록 → 중개사가 매물 확인 → 중개사가 구매자 확보 → 판매자 거래 성사
```

이 고리에서 **가장 먼저 임계점을 넘어야 할 주체는 판매자**다. 판매자 매물이 없으면 중개사도 구매자도 플랫폼에 머물 이유가 없다. 현재 MyHome의 판매자 유입 전략은:

- 공개 `/listings`·시세 페이지의 SEO 유입
- 관리자 대리 등록 기능
- 플랫폼 이용료 0원

이 정도로는 특히 **"내 집 매물"이라는 감정적·실용적으로 민감한 자산**을 신규 플랫폼에 맡기도록 유도하기 어렵다. 경쟁자(네이버부동산)의 신뢰도가 압도적으로 높기 때문이다.

### 5.2 수익 모델 공백의 연쇄 효과

CLAUDE.md에 "결제 시스템 미구현"이라고 명시되어 있다. 이는 단순한 기능 부재가 아니라 **사업 지속성과 성장 모두를 제약하는 근본 문제**다.

- 수익이 없으면 **마케팅 예산이 없다** → 사용자 유입 정체
- 수익이 없으면 **중개사 모집 인센티브를 제공할 자금이 없다**
- 수익이 없으면 **운영 인력 확충이 불가능하다** → 매물 검증·분쟁 조정 병목
- 무료 구조는 초기 진입 장벽을 낮추는 장점이 있으나, 임계점 돌파 후에도 같은 구조를 유지하면 지속 성장이 불가능하다

### 5.3 관리자 개입의 한계

현재 관리자는 매물 검증(pending → active), 대리 등록, 전체 매물 관리, 중복 감지 등의 역할을 맡는다. 초기에는 품질 관리에 효과적이지만:

- 매물 수 증가 시 검증이 병목이 된다
- 중개사 승인·분쟁 조정 등 더 복잡한 판단이 필요한 업무에 대한 프로세스가 명시적으로 없다
- 관리자 의존도가 높을수록 확장 비용이 선형 증가한다

## 6. 유인 성립 논리 매트릭스

각 사용자 관점에서 "이 앱을 쓸 이유가 논리적으로 성립하는가"를 다섯 가지 질문으로 평가한다.

| 질문 | 판매자 | 중개사 | 구매자 |
|------|:---:|:---:|:---:|
| 이득이 명확한가? | ○ | △ | △ |
| 경쟁 앱보다 나은가? | ○ | △ | ✕ |
| 초기에도 작동하는가? | △ | ✕ | ✕ |
| 지속 사용 이유가 있는가? | △ | △ | △ |
| 대체 불가능한 가치가 있는가? | ○ (MLS 구조) | △ | ✕ |

**해석**
- 판매자: 가치 제안이 논리적으로 성립하며 대체 불가 요소(MLS)가 있다. **가장 공고한 주체**.
- 중개사: "무료"라는 단일 축으로만 유인이 형성되어 있어 체급과 유형에 따라 차이가 크다.
- 구매자: 현재로는 경쟁 앱을 대체할 이유가 명확히 없다. **가장 취약한 주체**.

## 7. 보완 제안

우선순위에 따라 세 단계로 제시한다.

### 긴급 (P0) — 생존에 직결

1. **구매자 검색 UX 강화**: 가격 범위·전용 면적·건축 연도·방 수 필터, 지도 기반 탐색, 시세 조회와 매물 목록 간 내비게이션. 매물 공급량이 적어도 "탐색 경험"으로 체류를 유도해야 한다.
2. **중개사 모집 인센티브 프로그램**: 초기 진입 중개사에게 신뢰도 보호 기간(예: 첫 3개월 통계 집계 제외), 지역 우선 배정권, 성과 배지 등을 제공하여 Cold Start 콘텐츠를 확보한다.
3. **초기 매물 Seeding 전략**: 관리자 대리 등록 확대, 특정 지역(예: 1-2개 구) 집중 공략, 파트너 중개사와의 초기 매물 업로드 계약 등으로 매물 임계점을 빠르게 확보한다.

### 중요 (P1) — 사용자 만족도 상승

4. **BrokerOffer UI 완성**: 경쟁 입찰 구조가 완성되면 기존 앱과의 차별성이 뚜렷해진다. 모델만 있고 UI가 없는 현재 상태는 가장 아까운 공백이다.
5. **판매자 배포 대상 선별권**: 특정 중개사 차단, 지정 중개사 우선 배포 등의 옵션을 제공하여 프라이버시 우려를 해소한다.
6. **구매자 알림 시스템**: 관심 지역 신규 매물, 찜 매물 가격 변동, 시세 추이 알림 등으로 재방문 동기를 구축한다.

### 수익화 (P2) — 지속 가능성 확보

7. **중개사 프리미엄 상위 노출**: 신뢰도 기반 노출과 병행하되, 일부 슬롯은 유료 노출로 운영. 광고 수익 확보.
8. **전자계약 연동 수수료**: 파트너 연동을 통해 계약 단계에서 정액 수수료를 수취. 플랫폼이 "등록부터 계약까지" 이어지는 구조를 완성.

## 8. 결론

MyHome의 설계 의도는 한국 부동산 시장의 구조적 문제를 정조준하고 있으며, **판매자 관점에서는 유인과 구조가 모두 논리적으로 성립한다**. MLS라는 대체 불가의 가치 제안이 핵심 동력이다.

반면 **중개사 관점의 유인은 "무료"에 과도하게 의존**하여, 대형 중개사 유치와 신뢰도 시스템의 Cold Start 문제가 해결되지 않았다. 중개사 측 모집 전략과 최소 수익 모델이 동시에 필요하다.

**가장 심각한 지점은 구매자다.** 현재 구조로는 구매자가 기존 앱을 놔두고 MyHome을 주력으로 쓸 이유가 논리적으로 성립하지 않는다. 매물 공급량, 검색 UX, 알림 등 기초 체력 자체가 경쟁 앱 대비 열세다.

따라서 MyHome이 "3자가 모두 유인을 느끼는 플랫폼"이 되기 위해서는 다음 세 축의 보강이 필수다:

1. **구매자 UX 대대적 개선** (탐색·필터·알림)
2. **중개사 초기 모집 및 보호 장치**
3. **최소한의 수익 모델** 도입을 통한 자기 지속 구조

이 세 가지가 갖춰지지 않으면 플랫폼은 구조만 존재하고 사용자는 머물지 않는 상태에서 정체될 가능성이 크다. 반대로 이 세 축을 보강하면, 판매자 중심의 강력한 유인을 기반으로 한국형 부동산 MLS의 선도 모델이 될 잠재력은 충분하다.
