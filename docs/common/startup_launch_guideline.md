# MyHome 창업 진입 가이드라인

> 작성일: 2026-04-26
> 전제: [user_incentive_analysis.md](user_incentive_analysis.md), [cross_industry_case_studies.md](cross_industry_case_studies.md), [structural_risks_at_scale.md](structural_risks_at_scale.md) 의 시장·리스크 분석을 토대로, 이를 **실제 사업화**하기 위한 광범위 가이드라인.
> 대상: 솔로 엔지니어 → 창업가 전환을 준비하는 단계

## 0. 본질 인식 전환 — "코드는 끝이 아니라 시작의 5%"

> **"제품이 있다 ≠ 사업이 있다"**

지금까지 만든 건 **사업의 인프라**다. 진짜 사업은 사용자, 매출, 신뢰, 법적 지위, 운영 프로세스, 팀, 자본의 합이다. 코드는 그중 1개 축에 불과하다.

### 솔로 엔지니어 창업이 망하는 5가지 패턴

1. 계속 기능을 추가함 (코딩이 가장 익숙해서) — 사용자 0명인데 P0 리스크 24개를 더 만듦
2. 시장 검증 없이 출시 → "왜 안 쓰지?" 멘붕
3. 법인·법무·세무 미루다가 첫 사고에서 개인 책임 폭탄
4. 자본 없이 6개월 버티다 본업 복귀 (생계 압박)
5. "혼자 다 한다"는 자존심 — 해당 도메인 전문가 영입 안 함

이 5가지를 회피하는 것이 가이드라인의 뼈대다.

## 1. 창업은 5개 트랙을 동시에 굴리는 일

각각 별도 트랙이다. 하나만 잘하면 사업이 안 된다.

### 트랙 A — 법무·법인 (가장 미루기 쉬우나 가장 위험)

**즉시 결정할 것**

- **법인 설립 시점**: 매출 발생 전이라도 **공동창업자 영입·외부 투자·계약 체결 직전**에 필요. 보통 출시 30일 전 법인 설립
- **공인중개사법 자문 (필수)**: MyHome은 회색지대. 변호사 1명에게 30~50만원으로 1차 의견서 받기
  - 핵심 질문: "관리자 대리 등록과 자동 매칭이 '중개행위' 또는 '알선'으로 해석될 가능성?"
  - 직방·다방이 2010년대에 공인중개사협회와 충돌한 판례 검토 필수
- **약관·개인정보처리방침**: `_reference/legal/` 의 기존 문서는 일반 앱 약관 수준 → 부동산 거래는 단건 손해액이 수억 → 부동산 전문 변호사 검토 필수
- **배상책임보험 가입**: "허위 매물 책임" P0 리스크 → IT 전문 보험사(예: 삼성화재 사이버보험) 견적

**비용 감각**

| 항목 | 금액 |
|------|------|
| 법인 설립 | 50~100만원 |
| 변호사 자문 | 월 30~100만원 |
| 배상책임보험 | 연 100~300만원 |

### 트랙 B — 시장 검증 (Customer Discovery)

**가장 중요한데 엔지니어가 가장 빼먹는 트랙.**

분석 문서에 진단은 있다 — 판매자 7/10, 중개사 5/10, 구매자 4/10. **실제 인터뷰로 검증해야 한다.**

**90일간 해야 할 5가지**

1. **판매자 인터뷰 30명**: "최근 1년 내 집을 판/팔려고 한 사람" 만남. **앱을 보여주지 말고** 그들의 경험을 듣기. 듣고 싶은 답 유도 금지
   - "직전 거래에서 가장 답답했던 순간 1개"
   - "중개사 1명에게만 맡긴 이유"
   - "다른 동네 중개사도 같이 봐주면 어떨 것 같은지"
2. **공인중개사 인터뷰 20명**: 지역 부동산 직접 방문. 명함 받고 차 한 잔. 본인을 "솔로 개발자"로 솔직히 소개
   - "직방·네이버부동산에 매달 광고비 얼마?"
   - "광고 ROI 측정하는가?"
   - "신규 플랫폼이 들어오려면 무엇을 줘야 옮길까?"
3. **타겟 1개 동/구 선정**: 당근마켓 판교 모델. 매물 100건이 한 동에 모이면 자가 증식. 100건이 전국에 흩어지면 죽음
4. **경쟁사 1주 사용**: 네이버부동산·직방·다방 매도자/구매자 양쪽으로 등록·문의 직접 해보기. 어디가 끔찍한지 체감
5. **Pre-launch waiting list 페이지**: 메인 도메인에 "이런 서비스 곧 나옵니다, 알림 신청" 한 페이지. 광고 1만원만 돌려도 진심 관심도 측정 가능

**핵심 원칙**

> 내가 만든 솔루션이 좋은가를 묻지 말고, **그들의 문제가 진짜인가**를 묻는다.

추천 도서: **The Mom Test** (Rob Fitzpatrick)

### 트랙 C — 운영 시스템

코드 외에 사업이 굴러가려면 필요한 것들. 솔로일 때부터 갖춰야 한다.

| 영역 | 도구/방법 | 우선순위 |
|------|----------|---------|
| 회계·세무 | 세무사 월 10~20만원 위탁 | 법인 설립과 동시 |
| 고객 지원 | 카카오 채널 + 이메일 1개 | 출시 전 |
| 모니터링 | Firebase Crashlytics + Sentry | 출시 전 |
| 분쟁 처리 | SOP 문서 1장 (3일 내 1차 응답 등) | 출시 전 |
| 매물 검증 | 등기부 자동 확인 + 매뉴얼 더블체크 | 출시 전 |
| KPI 대시보드 | Mixpanel/Amplitude (무료 티어) | 출시 1주 내 |
| 백업·재해복구 | Firestore 자동 백업, 키 관리 | 즉시 |
| 데이터 거버넌스 | 개인정보 보관·파기 정책 | 출시 전 |

### 트랙 D — 자본

**현실 점검**: 솔로 6개월 → 1.5년이 정석. 이 기간 **본인 생활비 + 운영비**를 어떻게 댈 것인가?

**한국에서 가능한 자본 조달 경로**

1. **자기자본** (가장 빠르고 자유로움) — 6~12개월치 생활비 + 운영비 확보
2. **정부지원사업** (부동산 PropTech는 관심 분야)
   - **창업진흥원 예비창업패키지**: 최대 1억, 만 39세 이하 또는 예비창업자
   - **TIPS** (민간 + 정부 매칭): 최대 5억, 시드 단계
   - **K-Startup**: 다양한 트랙
   - **각 지자체 청년창업지원**: 서울 SBA 등
3. **엔젤 투자**: 5천만~3억. PropTech 엔젤 그룹 — **D.CAMP, 서울대 엔젤투자, 본엔젤스** 의 부동산 트랙
4. **시드 VC**: 매출 또는 강한 트랙션 필요. 너무 이르면 거절당하고 평판만 소모
5. **부트스트래핑**: 컨설팅·외주로 본인이 자금 댐 (가장 흔하지만 시간 더 걸림)

**추천 경로**

> 자기자본 6개월 + 예비창업패키지 신청 → 검증된 수치(매물 N건, 거래 N건)가 나오면 시드

### 트랙 E — 팀

**솔로로는 한계**. 분석 문서에서 P0로 잡힌 것들 중 절반은 솔로가 못 한다.

**최소 영입 1명: 부동산 산업 도메인 전문가**

- 전직 공인중개사, 부동산 회사 영업·기획 출신
- 역할: 중개사 영업, 산업 협회 네트워크, 법적 회색지대 감지
- 보상: 공동창업자급 지분(10~25%) + 작은 시드 시 약간의 급여

**다음 영입 후보**

- 마케팅·그로스 1명 (출시 직후)
- 운영·CS 1명 (매물 100건 돌파 시)
- 백엔드/데이터 엔지니어 1명 (시드 후)

## 2. 첫 90일 액션 플랜 — 주차 단위 구체 작업

각 주차 끝에 결과물 1개씩.

| 주차 | 핵심 작업 | 결과물 |
|------|---------|-------|
| 1 | 변호사 자문 1차, 법인 설립 절차 시작 | 자문 의견서 1장, 법인 설립 신청 |
| 2 | 타겟 지역 선정 (1개 구), 매물 50건 시드 계획 | 지역 분석 노트, 시드 계획서 |
| 3-4 | 판매자 인터뷰 10명 + 중개사 인터뷰 5명 | 인터뷰 노트 15개, 패턴 정리 |
| 5 | Pre-launch 랜딩 페이지 + 광고 1만원 | 대기자 명단, CPC/CTR 데이터 |
| 6 | Crashlytics + 핵심 5개 플로우 자동 테스트 | CI 통과, 크래시 0% 확인 |
| 7 | Open Beta 전환, 타겟 지역에서 매물 10건 시드 | 베타 출시 |
| 8 | 중개사 5명 영입 (직접 방문) | 중개사 5명 합류 |
| 9-10 | 첫 거래 1건 성사 (어떤 식으로든) | "거래 1" 사례 연구 |
| 11 | 인터뷰 추가 + 사용 데이터 분석 → Pivot 결정 | 회고 보고서 |
| 12 | 정부지원사업 신청서 제출 | 예비창업패키지 지원 완료 |
| 13 | 도메인 전문가 영입 면접 시작 | 후보 3명 미팅 |

### 90일 후 평가 기준

- 매물 등록 30건+
- 활성 중개사 5명+
- 거래 1건 이상
- 인터뷰 30회 이상
- 자본 12개월 확보 (자기자본 + 지원사업)

**이 기준 미달이면 Pivot 또는 Pause를 진지하게 검토**

## 3. 한국 부동산 PropTech 특수성

일반 SaaS 가이드에 없는 한국·부동산 특화 포인트.

1. **공인중개사협회의 정치력**: 직방·다방·MyHome 같은 플랫폼은 자주 협회와 충돌. **선제적 협력**이 정공법
2. **국토교통부·과기정통부 정책**: 매년 PropTech 육성 정책. KISA 정보보호 인증, 마이데이터 사업 등 연계
3. **실거래가 공개의 양면성**: 공공 데이터지만 가공·유통에 가이드라인 있음
4. **부동산 거래는 평생 0~3회**: [user_incentive_analysis.md](user_incentive_analysis.md) 에서 도출한 판매자 1회성 소비 구조 → **재방문 동기 설계가 마케팅 핵심**
5. **지역 신문·동네 카페·맘카페**: 부동산은 하이퍼로컬 → 페이스북 광고보다 동네 커뮤니티 침투가 훨씬 효율적
6. **세금 이슈**: 거래 완료 신고 회피 동기가 강함 → 강제하면 이탈, 안 하면 데이터 손실. [structural_risks_at_scale.md](structural_risks_at_scale.md) §3.1 의 P0 그대로

## 4. 지금 즉시 할 일 1개만 고른다면

> **"이번 주 내로 공인중개사 5명을 직접 만나라"**

코드 단 한 줄도 추가하지 말 것. 노트북 닫고 사무실 5곳 방문. 그 5번의 대화가 향후 6개월 의사결정의 90%를 좌우한다.

- 그들이 "이거 좋겠는데?" 라고 말하지 않으면 **무엇을 만들든 안 팔린다**
- 그들이 "어 이건 진짜 필요해" 라고 말하면, **나머지는 그저 실행 문제**

## 5. 가이드라인 3대 원칙

1. **5개 트랙 동시 진행** — 코드만 파지 말 것
2. **하이퍼로컬 + 깊은 검증** — 전국 출시는 환상, 1개 동·구·판매자 30명 인터뷰가 진짜
3. **재무·법무 안전망 먼저** — 부동산은 단건 사고 1번에 끝

## 6. 다음 단계 산출물 후보

| # | 산출물 | 예상 분량 | 우선순위 |
