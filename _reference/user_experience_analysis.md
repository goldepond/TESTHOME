# MyHome MLS 앱 - 사용자별 경험 상세 분석

> 작성일: 2026-04-05
> 목적: 구매자, 판매자, 중개사 각각이 앱에서 어떤 경험을 하는지 전체 여정을 정리하고, 좋은 경험과 나쁜 경험을 식별한다.

---

## 1. 구매자 (매수 희망자)

### 1-1. 전체 여정

```
앱 진입 (로그인 없이 가능)
  ↓
공개 매물 탐색 (/listings)
  ↓
매물 상세 확인 (/property/{id})
  ↓
"이 매물 문의하기" 클릭 → 로그인 필요
  ↓
문의 접수 (선택 메모 입력)
  ↓
중개사 자동 배정 대기
  ↓
배정된 중개사가 연락
  ↓
방문 → 계약 (앱 밖에서 진행)
```

### 1-2. 화면별 상세 경험

#### 랜딩 페이지
- "먼저 매물 둘러보기" 버튼으로 로그인 없이 탐색 가능
- 카카오/Google/이메일 로그인 옵션 제공
- 이전 로그인 방법을 기억해서 "지난번에 사용한 방법" 힌트 표시

#### 공개 매물 목록 (/listings)
- **검색**: 도로명, 건물명, 아파트명으로 검색
- **필터**: 지역 칩 (전체/지역별), 거래 유형 칩 (매매/전세/월세)
- **매물 카드에 표시되는 정보**:
  - 대표 사진
  - 거래 유형 배지 (컬러 구분)
  - 가격 (한국식 포맷)
  - 주소 (동/호수 제거된 안전한 형태)
  - 면적, 층수, 방 수, 건물명
- **반응형**: 모바일 1열, 데스크톱 2~4열 그리드
- 비로그인 사용자에게 하단 배너: "중개사님이신가요? 가입하시면..."

#### 매물 상세 (/property/{id})
- **볼 수 있는 것**: 사진 갤러리, 가격, 도로명 주소, 면적/층수/방수, 옵션(에어컨 등), 매력 포인트, 설명
- **볼 수 없는 것**: 매도인 연락처, 정확한 동/호수, 다른 구매자 정보, 협상 이력
- **핵심 CTA**: "이 매물 문의하기" 버튼
  - 비로그인 시: "로그인이 필요합니다" 스낵바
  - 로그인 시: 문의 다이얼로그 (메모 입력, 최대 200자)
  - 제출 후: "문의가 접수되었습니다. 중개사가 곧 연락드립니다." 확인

#### 문의 상태 추적
- 문의 후 상세 페이지에서 실시간 상태 확인 가능:
  - "중개사 매칭 중" (pending)
  - "중개사 배정 완료" (brokerAssigned)
  - "연락 완료" (contacted)
  - "방문 진행 중" (visiting)
  - "완료" (completed)
- 메모 수정, 문의 취소 가능

#### 실거래가 조회 (/market-price)
- 로그인 없이 사용 가능 (SEO 공개 페이지)
- 매매/전세/월세 탭 전환
- 주소 자동완성 검색
- 기간 선택: 6개월 / 12개월 / 24개월
- 상세 필터: 면적대, 층수, 건축년도, 계약구분, 검색 범위
- **결과 표시**: 평균가, 최저가, 최고가, 거래 건수
- **내 호가 비교**: 원하는 가격 입력하면 시장 평균 대비 위치 표시
- **중개 수수료 예상**: 거래 유형별 자동 계산

#### 알림
- 문의 관련 알림 수신 (중개사 배정, 연락 완료 등)
- 읽음/안읽음 구분, 일괄 읽음 처리
- 알림 탭하면 관련 매물 상세로 이동

### 1-3. 좋은 경험

| 경험 | 이유 |
|------|------|
| **로그인 없이 매물 탐색 가능** | 진입 장벽이 낮아 이탈률 감소. 관심이 생긴 후에만 로그인 요구 |
| **개인정보 보호** | 동/호수 미공개, 매도인 연락처 비공개로 안전한 탐색 환경 |
| **실거래가 무료 조회** | 시세 파악 후 합리적 의사결정 가능. "내 호가 비교" 기능으로 직관적 이해 |
| **문의 프로세스가 간단** | 버튼 1번 + 선택 메모만으로 문의 완료. 복잡한 양식 없음 |
| **문의 상태 실시간 추적** | "중개사 매칭 중 → 배정 완료 → 연락 완료" 단계별 진행 상황 투명 |
| **문의 취소/수정 자유** | 마음이 바뀌면 언제든 취소 가능. 부담 없는 탐색 |

### 1-4. 나쁜 경험 (예상)

| 경험 | 원인 | 심각도 |
|------|------|--------|
| **"중개사가 연락드립니다"인데 연락이 안 옴** | 중개사 자동 배정 시스템이 구현되어 있지만, 배정된 중개사가 실제로 연락하는지 강제하는 메커니즘 없음. 알림만 보내고 끝 | Critical |
| **문의 후 앱에서 할 수 있는 게 없음** | 문의 접수 → 중개사 연락까지 앱 내 소통 수단 없음. 전화를 기다리는 수밖에 없음 | High |
| **원하는 매물이 없을 때 알림 받을 방법 없음** | "이 지역에 새 매물이 올라오면 알려줘" 같은 관심 지역 구독 기능 없음 | High |
| **매물 비교가 어려움** | 찜/북마크 기능은 있지만, 여러 매물을 나란히 비교하는 기능 없음 | Medium |
| **중개사를 선택할 수 없음** | 시스템이 중개사를 배정함. 구매자가 중개사의 평판/전문성을 보고 직접 선택 불가 | Medium |
| **주소가 너무 추상적** | 개인정보 보호를 위해 동/호수 제거하면, 같은 건물 어떤 층인지 감이 안 옴 | Low |
| **모바일에서 실거래가 페이지 과밀** | 필터 옵션이 많아 작은 화면에서 복잡하게 느껴질 수 있음 | Low |

## 2. 판매자 (매도인)

### 2-1. 전체 여정

```
회원가입 (이메일/카카오/Google)
  ↓
프로필 완성 (이름, 전화번호)
  ↓
매물 등록 (일반 등록 또는 간편 등록)
  ↓
검증 대기 (자동 중복 검사)
  ↓
승인 → 활성 상태 (중개사에게 배포)
  ↓
중개사 열람 현황 확인
  ↓
방문 요청 수신 → 승인/거절
  ↓
승인 시 연락처 상호 교환
  ↓
전화로 조율 → 방문 → 협의 → 가계약 → 거래 완료
```

### 2-2. 화면별 상세 경험

#### 매물 등록 (2가지 방식)

**간편 등록 (Quick Registration) — 3단계 프로그레시브**
- **Step 0 — 주소**: 주소 검색 (자동완성) + 거래 유형 선택 (매매/전세/월세)
- **Step 1 — 가격**: 억/만원 분리 입력 + 프리셋 빠른 선택 버튼. 월세는 보증금+월세 이중 입력
- **Step 2 — 사진**: 최대 5장 업로드 + 선택적 상세 정보 (층수, 방 수, 방향, 옵션 등)
- 각 단계 완료 시 다음 단계 자동 해제 (잠금 → 해제 애니메이션)

**일반 등록 (Full Registration) — 단일 폼**
- **필수**: 주소, 희망가
- **선택**: 협상 가능 여부, 최소 희망가, 입주 가능 시기, 수리 상태, 옵션 (16종), 매력 포인트 (14종), 사진 (최대 5장), 수리 내역
- 미리보기 기능으로 등록 전 확인 가능
- 뒤로가기 시 미저장 데이터 경고 다이얼로그

#### 판매자 대시보드

**빈 상태** (매물 없을 때):
- 로켓 아이콘 + "첫 매물을 등록해보세요!" 안내

**매물이 있을 때**:
- **상단 통계 카드** (코랄 그라데이션):
  - 좌: 응답 대기 건수
  - 우: 승인 완료 건수
  - 최고 희망가 표시 (있을 경우)
- **상태 필터 탭**: 전체 / 활성 / 대기 / 협의중 / 거래완료 / 종료 (각각 건수 표시)
- **매물 카드별 표시 정보**:
  - 대표 사진 + 상태 배지 (활성/문의중/협의중/가계약/거래완료)
  - 방문 요청 알림 배지 (오렌지, "방문 요청 N건")
  - 주소, 건물명, 희망가
  - 최고 희망가 (초록색, 있을 경우)
  - 중개사 참여 프로그레스 바: 열람(파랑) / 대기(주황) / 승인(초록)
  - "요청 관리 (N건)" 빠른 액션 버튼

#### 매물 상세 (판매자 전용 뷰)

- 사진 슬라이더 + 상태 배지
- 주소, 가격, 협상 가능 여부, 면적/층/방 정보
- 옵션 칩, 매력 포인트, 설명
- 방문 가능 시간 표시 (요일별 시간대)
- **중개사 참여 현황**: 열람/대기/승인 건수 통계

**방문 요청 관리 섹션**:
- 필터: 대기중 / 승인됨 / 전체
- 요청 카드별:
  - 중개사 프로필 (이름, 회사, 아바타) — 클릭 시 상세 프로필
  - **희망가** (초록색 대형 텍스트, 우측 정렬)
  - 방문 희망 일시 (캘린더 아이콘)
  - 중개사 메시지 (있을 경우)
  - **"거절"** 버튼 (빨간 테두리) / **"승인 (연락처 교환)"** 버튼 (초록 배경)
- 정렬: 희망가 높은 순 → 최신 순

**승인 플로우**:
1. "승인 (연락처 교환)" 클릭
2. 다이얼로그: "중개사에게 공개할 연락처를 입력해주세요"
3. 전화번호 입력 → 확인
4. 양쪽 연락처 교환 완료 + 타임스탬프 기록

**중개 제안 섹션** (공개 페이지에서 온 제안):
- 중개사별 카드: 이름, 회사, 전화, 한마디(어필), 제출 시간
- "이 중개사 선정" 버튼 → 선정 시 다른 대기 제안 자동 미선정

**상태 전이 버튼**:
- inquiry → "협의 진행으로 변경"
- underOffer → "가계약 완료로 변경"
- depositTaken → "거래 완료 처리" (최종 가격/중개사 입력)

#### 매물 수정
- 수정 가능: 사진(최대 10장, 드래그 재정렬), 가격, 협상 여부, 건물명, 방문 가능 시간
- 수정 불가: 주소 (등록 후 변경 불가)
- 사진 관리: 대표 사진 지정, 순서 변경, 삭제, 추가

#### 알림 (판매자 수신)
- 방문 요청 수신, 방문 승인/거절/취소, 시간 조율 요청
- 가계약 완료, 거래 완료, 매물 만료
- 매물 검증 승인/거절
- 중개 제안 수신, 협상 시작, 역제안
- 상태 변경 (inquiry, underOffer)

### 2-3. 좋은 경험

| 경험 | 이유 |
|------|------|
| **간편 등록 3단계로 빠른 등록** | 주소 → 가격 → 사진, 최소 정보만으로 등록 가능. 복잡한 양식에 지치지 않음 |
| **연락처 비공개 원칙** | 방문 승인 전까지 전화번호 완전 비공개. 스팸/무분별한 연락 차단 |
| **희망가 비교로 최적 중개사 선택** | 방문 요청이 희망가 높은 순으로 정렬되어 가장 유리한 제안 한눈에 파악 |
| **중개사 참여 현황 실시간 확인** | 열람/대기/승인 프로그레스 바로 매물의 시장 반응을 직관적으로 파악 |
| **승인 시 연락처 교환 명시적 동의** | 다이얼로그에서 "공개할 연락처"를 직접 입력 → 어떤 정보가 공유되는지 통제감 |
| **방문 가능 시간 사전 설정** | 요일/시간대별 가능 시간을 미리 설정 → 불가능한 시간에 요청 방지 |
| **미리보기 후 등록** | 등록 전 완성된 매물 카드 미리보기 가능 |

### 2-4. 나쁜 경험 (예상)

| 경험 | 원인 | 심각도 |
|------|------|--------|
| **"자동 배포됩니다"인데 중개사가 안 봄** | `approveProperty()`가 상태만 변경하고 실제 `broadcastProperty()` 미호출. 매도인은 배포됐다고 믿지만 중개사 목록에 안 뜰 수 있음 | Critical |
| **매물 상태가 갑자기 바뀜** | 방문 승인하면 자동으로 active→inquiry, 협의 시작하면 inquiry→underOffer로 전이. 알림도 없고 되돌릴 수도 없음. "왜 갑자기 상태가 바뀌었지?" | High |
| **방문 승인했는데 중개사가 안 옴 (노쇼)** | 노쇼 기록은 가능하지만 중개사에게 실질적 패널티 없음. 신뢰도 점수에 반영되나 중개사가 이를 볼 수 없어 억제 효과 미미 | High |
| **등록 후 아무 반응 없는 기간** | 검증 대기 → 승인 → 배포까지 시간이 걸리는데, 이 기간 동안 진행 상황 안내 부족. "내 매물 어떻게 된 거지?" | High |
| **거절 후 중개사에게 사유 전달 불가** | "거절" 버튼만 있고 거절 사유 입력란 없음. 중개사가 왜 거절당했는지 모름 → 같은 실수 반복 | Medium |
| **동시 수정 충돌** | 판매자가 매물을 수정하는 동안 중개사가 같은 매물을 열람 중. 낙관적 잠금(optimistic locking) 없어서 데이터 불일치 가능 | Medium |
| **주소 변경 불가** | 등록 시 주소 오류 입력하면 수정 불가. 삭제 후 재등록해야 함 | Medium |
| **방문 충돌이 자동 처리됨** | 한 중개사 승인하면 ±30분 내 다른 요청이 자동 reschedule. 판매자가 "어떤 중개사가 더 나은지" 비교할 기회 없이 선착순 처리 | Medium |
| **사진 업로드가 느릴 수 있음** | 최대 5~10장 이미지를 Firebase Storage에 순차 업로드. 대용량 사진일 경우 대기 시간 발생 | Low |

## 3. 중개사 (공인중개사)

### 3-1. 전체 여정

```
중개사 가입 (등록번호, 대표자명, 상호명, 연락처, 이메일, 비밀번호)
  ↓
관리자 인증 대기 (verified: false)
  ↓
인증 완료 → 전체 기능 해제
  ↓
매물 탐색 (지역/가격/유형/상태 필터)
  ↓
매물 상세 확인 → "조건 제안" (방문 요청)
  ↓
희망가 + 방문 희망 일시 + 메시지 입력
  ↓
판매자 승인 대기
  ↓
승인 시 → 연락처 교환 → 전화 조율
  ↓
방문 → 협의 → 가계약 → 거래 완료
  ↓
성과 기록 (수수료 자동 계산)
```

### 3-2. 화면별 상세 경험

#### 가입 & 인증

**가입 양식**:
- 중개업 등록번호 (필수, 숫자만)
- 대표자명 (필수)
- 사업자 상호 (필수)
- 전화번호 (필수, 숫자만)
- 이메일 (필수, 형식 검증)
- 비밀번호 (필수, 6자 이상) + 확인

**인증 대기 상태**:
- 대시보드 접근 가능하지만 "관리자 인증 대기 중" 배너 표시
- 매물 탐색은 가능하지만 방문 요청 제출 불가
- "인증하면 더 많은 기능을 쓸 수 있어요" 가이드:
  - 매물 방문 요청
  - 판매자 연락처 교환
  - 성과 리포트 확인

#### 대시보드 (5탭 구성)

**Tab 0: 매물 (Browse Properties)**
- **2단 필터 바**:
  - 1단: 지역 드롭다운 + 상태 필터 칩 (전체/신규/문의중/협상중/가계약) + 목록/지도 토글
  - 2단: 가격대 필터 (슬라이더 0~50억 + 프리셋) + 매물 유형 + 초기화
- **매물 카드 표시 정보**:
  - 상태 배지 (컬러: 신규=초록, 문의중=파랑, 협상중=주황, 가계약=보라, 완료=회색)
  - 검증 배지 (관리자 승인 시)
  - "참여중" 배지 (이미 제안한 매물)
  - 지역 라벨
  - 주소 + 희망가 (파랑 굵은 글씨)
  - **법정 최고 수수료율**: "법정 최고 X% (Y원)" — 수익 예상 가능
  - "조건 제안" 버튼 (미제안 매물) / "제안 수정" 버튼 (제안 완료 매물)
- **지도 뷰**: BrokerMapView로 매물 위치 시각화

**Tab 1: 관심 매물 (My Competing Properties)**
- 내가 제안/참여 중인 매물 목록
- **중개사 단계별 배지**:
  - 수신 (회색) → 열람 (파랑) → 요청 (주황) → 승인 (초록) → 완료 (보라)
- **단계별 안내 메시지**:
  - 수신: "새 매물이 도착했습니다"
  - 열람: "매물을 확인했습니다"
  - 요청: "방문 요청 후 판매자 응답 대기 중"
  - 승인: "판매자가 승인! 연락처가 교환되었습니다"
  - 완료: "거래가 완료되었습니다"

**Tab 2: 방문 요청 (My Proposals)**
- 내가 보낸 방문 요청 및 중개 제안 전체 목록
- 상태별 배지: 대기중 (주황) / 선정됨 (초록) / 미선정 (회색)
- 어필 메시지(한마디) 표시
- 제출 시간 + 선정일 (선정된 경우)

**Tab 3: 성과 (Results)**
- **중개사 프로필 카드**: 상호명, 인증 상태, 대표자명, 등록번호, 연락처, 소재지
- **가계약 성사 목록**: 매물별 주소, 최종 가격, 예상 수수료 (수수료율%)
- **거래 완료 목록**: 동일 형식, 보라색 "완료" 배지
- **수수료 자동 계산**: CommissionCalculator로 법정 요율 적용

**Tab 4: 구매 리드 (Buyer Leads)**
- 관리자가 배정한 구매자 문의 목록
- 상태 필터: 전체 / 신규 / 응답함 / 완료
- 문의 카드: 구매자 이름, 전화, 메시지, 문의일
- **상태 전진 버튼**:
  - brokerAssigned → "연락 완료" (초록)
  - contacted → "방문 진행" (청록)
  - visiting → "완료" (회색)

#### 방문 요청 (제안) 제출 플로우

1. 매물 카드에서 "조건 제안" 클릭
2. **바텀 시트** 열림:
   - 매물 희망가 표시 (참고용)
   - **희망가 입력** (필수, 만원 단위)
   - **방문 희망 일시** (필수):
     - 판매자 가능 시간 표시 (있을 경우): 요일별 오전/오후/저녁 슬롯
     - 날짜 선택 (내일~30일 후)
     - 시간 선택
   - **추가 메시지** (선택, 200자)
3. 모든 필수 입력 완료 시 "방문 요청하기" 버튼 활성화
4. 제출 → "방문 요청을 보냈습니다! 판매자 승인을 기다려주세요." 토스트
5. 자동으로 Tab 1 (관심 매물)로 이동

#### 설정 & 프로필
- 기본 정보 수정: 성명, 연락처
- 사업자 정보 수정: 사무소명, 사무소 주소 (등록번호는 읽기 전용)
- 소개 작성: 자유 텍스트 (최대 5줄)
- 인증 상태 표시: "인증 완료" (초록) 또는 "관리자 인증 대기 중" (주황)

#### 알림 (중개사 수신)
- 방문 승인/거절/시간 조율
- 매물 상태 변경 (가계약, 거래 완료, 만료)
- 경쟁 중개사 진행 상황
- 구매자 문의 배정
- 중개사 인증 완료/해제
- 중개 제안 결과

### 3-3. 좋은 경험

| 경험 | 이유 |
|------|------|
| **법정 수수료 자동 계산** | 매물 카드에 "법정 최고 X% (Y원)" 표시 → 수익성 즉시 판단, 시간 절약 |
| **판매자 가능 시간 확인 후 요청** | 판매자가 설정한 방문 가능 시간대를 보고 요청 → 거절률 감소 |
| **5탭으로 업무 전체 관리** | 탐색/관심/제안/성과/리드를 한 대시보드에서 → 별도 CRM 불필요 |
| **단계별 진행 상황 투명** | 수신→열람→요청→승인→완료 5단계가 명확히 표시 → 현재 상태 파악 용이 |
| **다양한 필터로 정밀 탐색** | 지역+가격+유형+상태 조합 필터 + 지도 뷰 → 관심 매물 빠르게 발견 |
| **구매자 리드 관리** | 배정된 구매자 문의를 앱에서 직접 관리, 상태 전진 → 업무 체계화 |
| **성과 기록 자동 누적** | 가계약/완료 건수와 수수료가 자동 집계 → 실적 관리 편의 |

### 3-4. 나쁜 경험 (예상)

| 경험 | 원인 | 심각도 |
|------|------|--------|
| **인증 대기 기간 동안 핵심 기능 차단** | 관리자가 수동 인증하므로 대기 시간 불확실. "언제 인증되나요?" 피드백 없음. 가입 직후 이탈 위험 | Critical |
| **제안 거절 시 사유를 알 수 없음** | 판매자가 "거절"만 누르고 이유 미기재. 중개사는 가격이 문제인지, 시간이 문제인지, 다른 중개사가 선정된 건지 모름 | High |
| **노쇼로 억울하게 찍힐 수 있음** | 판매자만 노쇼 기록 가능, 중개사 이의제기 불가. 실제로 방문했는데 판매자가 노쇼 처리하면 반박 수단 없음 | High |
| **다른 중개사와의 경쟁 상황 불투명** | 몇 명이 경쟁 중인지, 다른 중개사의 희망가는 얼마인지 전혀 알 수 없음. 블라인드 경쟁 | High |
| **승인 후 앱에서 할 수 있는 게 없음** | 연락처 교환 후 전화/카톡으로 전환. 협의 진행 상황을 앱에 기록하는 인센티브 없음 → 앱 이탈 | High |
| **신뢰도 점수를 본인이 볼 수 없음** | 행동 기반 평가 시스템이 있지만 중개사 자신의 점수/순위를 확인하는 화면 없음 | Medium |
| **시장 하락기에 정직한 제안이 패널티** | 제안가 편차(priceDeviation)가 1.0 미만이면 "저가 압박 경향"으로 분류. 시장 가격이 하락하면 합리적 제안도 패널티 | Medium |
| **구매자 리드 배정 기준 불명확** | 어떤 기준으로 구매자가 배정되는지 중개사가 알 수 없음. 공정성 의문 | Medium |
| **매물 정보 업데이트 알림 없음** | 판매자가 가격이나 조건을 변경해도 이미 제안한 중개사에게 알림 안 감 | Medium |
| **가입 시 등록번호 실제 검증 없음** | 아무 숫자나 입력해도 가입 가능. 관리자 인증 전까지는 무효한 등록번호로도 매물 열람 가능 | Low |

## 8. 핵심 개선 제안 (우선순위순)

1. **앱 내 메시징** — 연락처 교환 후에도 앱에서 소통 가능하게 (모든 사용자 경험 개선)
2. **배포 자동화 연결** — 승인 시 실제 중개사 배포 실행 (판매자 신뢰)
3. **중개사 인증 프로세스 개선** — 예상 소요 시간 안내 + 부분 기능 허용 (중개사 이탈 방지)
4. **거절 사유 시스템** — 판매자가 거절 시 사유 선택/입력 (중개사 학습)
5. **구매자 관심 지역 알림** — "이 지역 새 매물" 구독 기능 (구매자 재방문)
